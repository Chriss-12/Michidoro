# SDD lifecycle

| Phase | Output | Gate |
|---|---|---|
| Explore | Problem and context | Scope is understandable. |
| Propose | Intent, users, non-goals | Product direction is clear. |
| Requirements | `REQ-*` updates | Status and verification columns exist. |
| Design | Architecture approach | Dependency rules hold. |
| Tasks | Small work plan | Reviewable and traceable. |
| Apply | Implementation | Checks pass. |
| Verify | Evidence | Requirements can change status. |
| Archive | Summary | Docs and traceability are current. |
