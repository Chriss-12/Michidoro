# Entrega final

## Resumen

MichiFocus entrega una experiencia offline-first para planificar objetivos, gestionar tareas, trabajar con Pomodoro y exportar reportes locales en PDF.

## Alcance incluido

| Área | Estado |
|---|---|
| Tareas rápidas y planificadas | Incluido |
| Objetivos por fecha y progreso general por filas | Incluido |
| Calendario de planificación | Incluido |
| Inicio de Pomodoro desde tarea | Incluido |
| Pausa, descarte, reinicio y finalización anticipada | Incluido |
| Descansos cortos y largos | Incluido |
| Métricas por día, semana, mes y año | Incluido |
| Colores de avance en Home y Calendario | Incluido |
| Reportes PDF por día, semana, mes, año o rango | Incluido |
| Reportes con nombre, correo y gráficos seleccionados | Incluido |
| Carpeta configurable para reportes | Incluido |
| Backup local con exportación e importación | Incluido |
| Arranque inicial sin logo cuadrado | Incluido |
| Persistencia local | Incluido |
