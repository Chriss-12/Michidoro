# Guía rápida

1. Abrí la app.
2. Entrá a **Tasks**.
3. Escribí el título de una tarea y tocá **Agregar tarea**.
4. Usá el botón de check para marcarla como completada.
5. Usá editar o eliminar cuando necesites corregir la lista.
6. Filtrá por todas, activas o completadas.
7. Cerrá y volvé a abrir la app: tus tareas se conservan localmente.
