# Manual de instalación

## Requisitos

- Dispositivo compatible con la versión entregada de la app.
- Espacio disponible para instalar la aplicación y guardar datos locales.
- Permiso para instalar el paquete de la app si se entrega como APK.

## Instalación en Android

1. Recibí el archivo APK.
2. Abrí el APK desde el dispositivo.
3. Si Android lo solicita, permití la instalación desde la fuente correspondiente.
4. Completá la instalación.
5. Abrí MichiFocus.
6. Confirmá que la app inicia sin conexión a internet.

## Verificación inicial

Después de instalar:

- creá una tarea rápida;
- entrá a **Home > Planificación** y creá un objetivo;
- iniciá un Pomodoro desde una tarea;
- exportá un PDF desde **Home > Descargar estadísticas**;
- revisá o configurá la carpeta en **Settings > Reportes**.

## Notas sobre reportes

La app intenta guardar los reportes en **Descargas**. Si el dispositivo restringe esa ubicación, se puede configurar una ruta en **Settings > Reportes** o la app usará una carpeta local alternativa.
