# Manual de usuario

Guía para usar la app Pomodoro offline.

## Tareas

La sección de tareas permite organizar actividades del día sin conexión a internet.

- Crear tareas con un título.
- Editar tareas existentes.
- Marcar tareas como completadas o activas.
- Eliminar tareas con confirmación.
- Filtrar tareas por todas, activas o completadas.
- Conservar las tareas localmente al cerrar y volver a abrir la app.

## Funciones previstas

- Trabajar con sesiones Pomodoro.
- Organizar objetivos y calendario.
- Revisar reportes y exportar PDF cuando esas funciones estén disponibles.
